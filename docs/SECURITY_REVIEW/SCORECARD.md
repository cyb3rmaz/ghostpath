# GhostPath VPN Security & Production-Readiness Scorecard

| # | Category | Score (0–10) | Justification & Evidence |
|---|----------|:------------:|--------------------------|
| 1 | **Privilege Boundary & IPC** | **8 / 10** | Unix socket permissions tightened from `0666` to `0660` (`root:ghostpath`), `adm` group removed from `SO_PEERCRED` allowlist (`auth.rs`), concurrent connections capped at 32 via `Semaphore`, and JSON-RPC lines bounded to 1 MiB (`server.rs`). `ghostpathd` drops core dumps (`PR_SET_DUMPABLE=0`, `RLIMIT_CORE=0`, `umask(0077)`), and `systemd-analyze security` improved from `6.0 MEDIUM` to `4.2 OK`. Remaining gap: `ReadWritePaths` still includes specific `/etc/*` targets for timezone/GeoClue/resolv.conf. |
| 2 | **Untrusted Input & Parsers** | **8 / 10** | All protocol parsers (`vless`, `vmess`, `trojan`, `ss`, `vpn://`, `.conf` INI, subscriptions) enforce strict size/line limits, reject control characters and port `0`, and fail closed on invalid schemes/configs without falling back to `socks` or `127.0.0.1` (`singbox.rs`, `subscription.rs`). Property-based fuzzing (`amnezia_proptest`) passes. Remaining gap: `cargo-fuzz` libFuzzer harnesses were not run in this environment (proptest was used). |
| 3 | **SSRF & Network Fetching** | **9 / 10** | `safe_fetch_subscription()` (`engine.rs`) enforces `https://`, rejects embedded credentials, resolves DNS and checks every address against `is_public_ip()` (blocking loopback, RFC1918, link-local/`169.254.169.254`, CGNAT, ULA, IPv4-mapped IPv6), pins the validated IP with `reqwest::ClientBuilder::resolve()`, caps redirects at 3, caps body size at 4 MiB, and redacts URLs in logs. |
| 4 | **Secrets & Privacy** | **8 / 10** | `AwgInterfaceConfig` and `AwgPeerConfig` implement `Zeroize + Drop` and redact keys in `Debug`; `AwgBackend::stop()` clears `last_config`; `listNodes` redacts `rawLink` over IPC; `fs_safe::atomic_write_private()` writes configs/backups/journals with `0600` and `O_NOFOLLOW`; exact lat/lon removed from daemon logs; git history secret scan found no committed keys. Remaining gap: subscription URLs and profile `raw_link` are still stored in `0600` JSON on disk rather than OS keyring. |
| 5 | **Networking Correctness & Kill Switch** | **7 / 10** | `DaemonEngine::connect()` is now fail-closed with full rollback on error; `KillSwitch::enable()` accepts the dynamic interface (`ghost0` or `awg-ghost0`) and arms before routing/TUN setup; `CoexistenceManager` is wired into connect/disconnect; `TunDevice` gates mock fallback behind `dev-mock` and checks `ip` exit codes; `--recover` reverts kill switch, routes, DNS, and geo state. Remaining gap: `DnsProxy` (`127.0.0.1:10853`) is still a minimal responder rather than a full DoH forwarder (DNS relies on `resolvectl`/`resolv.conf` through `ghost0`). |
| 6 | **Concurrency & Crash Recovery** | **7 / 10** | `ghostpathd --recover` now disarms `inet ghostpath`, flushes table `5180` and rules `5180`/`5181`, reverts `systemd-resolved` / `/etc/resolv.conf`, and restores `/etc/localtime` and `/etc/geolocation`. Signal handlers no longer `expect()`. Remaining gap: `loom`/`shuttle` and multi-hour live soak tests in a full VM were not executed in this WSL environment. |
| 7 | **Rust Code Quality & Safety** | **9 / 10** | `#![forbid(unsafe_code)]` enforced on `ghostpath-core`, `ghostpath-proto`, `ghostpath-net`, `ghostpath-daemon` (lib), `ghostpath-cli`, and `ghostpath-gui`; `unsafe` is isolated to `ghostpath-tun` TUN syscalls and `harden_process()` in `ghostpathd/main.rs`, all with `// SAFETY:` comments. `cargo fmt --check` and `cargo clippy --workspace --all-targets -- -D warnings` pass with 0 errors. |
| 8 | **Supply Chain & Dependencies** | **8 / 10** | `cargo audit` found 0 vulnerabilities across 575 dependencies (only unmaintained warnings on transitive crates). `cargo deny check` passes (`advisories ok, bans ok, licenses ok, sources ok`). `packaging/bin/amneziawg-go.sha256` is verified in `build-deb.sh`. `npm audit` found 0 vulnerabilities across 301 packages. |
| 9 | **Desktop App & UI Security** | **8 / 10** | Tauri capabilities are minimal (`core:default`, `notification:default`, `deep-link:default`); CSP restricts `default-src 'self'`, `script-src 'self'`, `connect-src 'none'`; `single_instance.rs` rate-limits deep links; zero `dangerouslySetInnerHTML`/`eval()` sinks; `verify_no_demo_content.sh` passes; UI settings defaults aligned with backend (`1.1.1.1`/`8.8.8.8`). Remaining gap: `withGlobalTauri: true` and `style-src 'unsafe-inline'` remain for current frontend compatibility. |
| 10 | **Packaging & Lifecycle** | **7 / 10** | `.deb` packaging (`build-deb.sh`) sets `root:root` ownership, creates `ghostpath` system group, adds `geoclue-2.0` dependency, verifies `amneziawg-go` SHA-256, and runs `ghostpathd --recover` in `prerm`. Remaining gap: `lintian` and `shellcheck` were not installed (no passwordless `sudo` for `apt`) and clean-VM multi-distro install tests were not run in this environment. |
| 11 | **Testing & Verification** | **7 / 10** | All unit, integration, security, and proptest suites pass across all 7 crates. `cargo llvm-cov --workspace --summary-only` measured **57.50% line coverage** (8389 lines). Miri verified `ghostpath-core` pure-logic tests without UB. Remaining gap: live kernel `tun`/nftables packet-leak tests and `cargo-fuzz` corpus runs require a privileged VM/container. |
| 12 | **Documentation & Transparency** | **9 / 10** | `SECURITY.md`, `docs/TROUBLESHOOTING.md`, `docs/SECURITY_REVIEW/THREAT_MODEL.md`, `FINDINGS.md`, `TOOLING_OUTPUT.md`, `SCORECARD.md`, and `RESIDUAL_RISK.md` are complete, accurate, and honest about limitations without overclaiming anonymity. |

**Overall Weighted Readiness:** **7.9 / 10 (Production-Hardened Beta — ready for controlled Linux release after VM leak-test verification)**
