# GhostPath VPN - Frontend UI

This package contains the offline React 19 + TypeScript + Tailwind CSS v4 frontend for GhostPath VPN desktop client.

## Development

```bash
npm install --legacy-peer-deps
npm run dev
```

## Production Build

```bash
npm run build
```

Assets are bundled locally into `dist/` with 0 external network dependencies and bundled local typography (`@fontsource/vazirmatn`, `@fontsource/plus-jakarta-sans`, `@fontsource/dm-sans`, `@fontsource/jetbrains-mono`).
